# 러브 레터 / LOVE LETTER — v0.6

당신의 곁에 오래도록 머물러 준 당신의 반려 로봇, 비인간 기계에게 보내는 편지. 기계들이 알아들을 수 있게 바꿔드려요.

A letter to your companion robot, the non-human machine that has stayed by your side for so long. We’ll translate it into something machines can understand.

사이트: https://mmnmj.github.io/loveletter/

```
글 → UTF-8 / 7-bit ASCII → 비트 → 타공 좌표 → SVG / PDF → 레이저커팅
```

## 쓰는 법

1. **01 TEXT**에 한국어나 영어로 편지를 써요.
2. **교정**을 누르면 **02 교정된 언어**에 정리된 글이 나와요.
3. **변환**을 눌러 판형·여백·구멍 모양을 정하고 **적용 · 변환**.
4. **04 PERFORATION**에서 결과를 봐요. **VIEW 보기** 메뉴로 여백 가이드 / 그리드 / 0 가이드를 켜고 끌 수 있어요. (화면에서만 보이고 파일엔 안 들어가요)
5. **출력 · SVG / PDF**로 내려받아요.

설치나 서버가 필요 없어요. 모든 변환은 브라우저 안에서 일어나고, 글은 어디로도 보내지지 않아요.

## 글이 구멍이 되는 방식

| 입력 | 인코딩 | 한 칸 | 세로 행 |
|---|---|---|---|
| 영어만 | 7-bit ASCII | 1글자 | 7행 |
| 한글이 섞임 | UTF-8 | 1바이트 (한글 1글자 = 3칸) | 8행 |

- 한 칸의 비트를 위 → 아래로 놓고, **1인 자리만** 구멍을 뚫어요. 0은 자리만 차지해요.
- 한글이 한 글자라도 섞이면 글 전체가 UTF-8 8행이 돼요. 한 판 안의 줄 높이를 같게 하려고요.
- 영어만 있는 글은 이전 버전과 비트·좌표·SVG·PDF가 완전히 같아요.
- 예: `당` → `11101011 10001011 10111001` (3칸)

### 교정된 언어

글자 자체는 바꾸지 않고 모양만 정리해요.

- 맥에서 자모가 분리된 한글을 합쳐요 (NFC)
- 줄바꿈 통일(LF), 탭 → 공백, 겹친 공백·빈 줄 정리, 앞뒤 공백 제거
- 맞춤법 교정이나 번역은 하지 않아요

## 배치

**Column Layout (기본)** — 한 칸 = 세로 한 열. `Characters per row`(기본 14)칸마다 다음 줄로 넘어가요. 행 간격은 모두 같아요.

```
x = left + columnPitch / 2 + column × columnPitch
y = top + (rowGroup × 행수 + bitIndex) × rowPitch      // 행수 = 7 또는 8
columnPitch(auto) = (width − left − right) / charactersPerRow
```

위 여백(top)은 첫 구멍의 **중심** 위치예요. 판에 다 안 들어가면 자동으로 다음 판(페이지)을 만들어요.

**세로 정렬** — 기본은 위에서부터. 「세로 가운데」를 고르면 간격·열 위치는 그대로 두고, 판마다 남는 높이의 절반만큼 구멍 묶음 전체를 아래로 옮겨요. 행 간격을 직접 입력했을 때 아래가 비는 걸 맞출 때 써요.

**Continuous Bit Layout** — 비트를 왼쪽 → 오른쪽, 위 → 아래로 이어서 채워요.

### 기본값

| 항목 | 값 |
|---|---|
| 판형 | 300 × 450 mm |
| 여백 위/아래/왼/오 | 28 / 30 / 26 / 26 mm |
| 구멍 크기 / 선 두께 | 3.2 mm / 0.01 mm |
| 선 색상 | #FF0000, 채움 없음 |
| 구멍 모양 | ● 원 ◆ 마름모 ▲ 삼각형 ♥ 하트 ■ 사각형, 또는 직접 만든 SVG |

## 출력

- SVG·PDF 모두 실치수 mm, 채움 없는 벡터 외곽선이에요. 래스터 이미지는 없어요.
- 판이 여러 장이면 PDF는 여러 페이지, SVG는 한 파일 안에 판별 그룹으로 저장해요. `illustrator_svg_to_layers.jsx`를 Illustrator에서 실행하면 판별 레이어로 바뀌어요.
- **SVG 가로 구분선**: 한 줄(7행 또는 8행)마다 넣을 수 있는 편집용 선이에요. 레이저커팅 전엔 지우거나 절단 제외로 지정해 주세요.
- **사용자 지정 벡터**: 직접 만든 SVG를 올리면 구멍 좌표는 그대로 두고 모양만 바꿔요.
- 파일 이름 예: `Love_Letter_2026-11-27_234800_Text_UTF8_300x450_column_circle.svg`
